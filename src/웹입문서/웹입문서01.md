# 01. Visual Studio 첫실행
```chsarp
Console.WriteLine("C# 공부를 시작합니다");
Console.WriteLine("오늘의 목표: 직접 실행하기");
```
## 실수를 했는가?
세미콜론을 빠뜨려서 헤매었다.
Console WriteLine 소괄호 안에 큰따옴표를 넣지 않았다.
## 다음의 각오
코드를 다 작성한 뒤에는 문장 끝에 세미콜론(;)이 잘 붙었는지 습관처럼 확인하겠다.
문자열을 출력할 때는 큰따옴표("")로 감싸는 기본 문법을 놓치지 않겠다.
에러 메시지가 뜨더라도 당황하지 않고, 오타나 기호 누락부터 차근차근 살펴보는 디버깅 습관을 들이겠다.
