# 용어

솔루션 : 프로젝트들을 관리하기 위한 단위
namespace : 관련 형식의 이름을 묶고 이름 충돌을 줄이는 역할
 - 이름이 같으면 컴퓨터의 입장에서 어떻게 구별해? 에러! 해결하기 위해서 존재한다.
 - 코드는 혼자 작업하는 게 아니다. 게임 만들때 필요한 명사를 말해보세요. 캐릭터, 배경, 그래픽 / A가만든 Character B가 만든 Character
 - namespace Flowstudy{}
static : 이 클래스의 객체를 new로 만들 수 없고, 객체 생성 없이 정적 멤버를 사용한다
class : 데이터와 동작을 정의하는 형식
메서드 : 클래스 내부에서 정의된 함수의 작업 단위
Program : 메서드 등 멤버를 정의
 - static class Program{}
void : 호출한 쪽에 결과값을 반환하지 않음
Main : 프로그램 진입점의 처리 정의
 - static void Main()
Console.WriteLine(); : 실행 중 콘솔에 문장 출력
() : 메서드 선언.호출의 매개변수나 인수를 감쌈
{} : 본문이나 묶음의 경계 표시
; : 대입문,호출문 같은 문장을 끝냄
변수 : 현재 값을 기억하고, 필요할 때 읽거나 바꿀 수 있게 하는 것
int : 정수를 저장하는 자료형
초기화 : 선언할 때 첫 값을 지정하는 것
= : 값을 저장하는 대입 연산자
리터럴 : 코드에 직접 적은 값
