# 게임루프
    - 입력이 있든 없든 스스로 계속 도는 반복문
## 무엇을
    - 게임 루프를 입력, 갱신, 렌더링을 프레임(한 바퀴)로 표현한 것이다.

    - 입력은 이벤트로 만들어줘
    - 갱신은 delta time 표현하도록 구성해라.
    - 화면을 그려줘(render)

## 무슨 문제가 발생했나요?
    - 똥이 4방향으로만 오니까 너무 단조로워졌다. -> 대각선 이동과 똥 추가
    - 대각선 이동 시 처음 한 번만 대각선으로 가고 이후엔 한쪽 방향으로만 꺾였다. -> 키보드의 실시간 물리적 눌림 상태를 감지하게 변경(key State)
    - 게임오버할때 왜 죽었는지 모르고 넘어가버렸다. -> 충돌 순간의 마지막 화면 유지, 충돌한 위치의 플레이어를 X로 표시, 게임 보드 바로 아래쪽에 게임 오버 창 출력, 2초간 화면을 정지
