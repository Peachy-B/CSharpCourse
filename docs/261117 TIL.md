# 깃을 통한 프로젝트 관리

- 수업 내용 정리
    
    1> 깃과 깃허브
    : 깃은 내 PC에서 파일의 변경 상태와 커밋 이력을 관리, 깃허브는 깃 저장소를 호스팅하고 협업 기능을 제공
    
    2> 깃을 올리는 과정 설명
    : 커밋으로 로컬에 기록하며 푸쉬와 풀로 원격 공유가 가능

    3> 로컬과 리모트 / 이 사이에 파일의 흐름 이해했는가
    : 로컬은 물리적으로 접근가능한 내 PC, 리모트는 온라인으로 접근가능한 공간

  [육하원칙]
- 누가 깃을 쓰는가? 컴퓨터 프로그래머
- 왜 쓰는가? 업데이트를 할때마다 기록하기 위해서
- 언제 쓰면 좋을까? 파일 또는 폴더의 내용을 변경할 때
- 어디에서 활용되고 있을까? 프로그래밍의 모든 과정

  [힌트: ‘오늘 배운 것’ 대신 언제 무엇이 잘못됐는가]
- 상황·환경·입력·문제: __   __
  [힌트: 독자가 같은 출발점을 만들 수 있게]
- 가설·시도·관찰 결과: ____
  [힌트: 실패도 포함하되 실제 수행한 내용만]
- 해결·원인·검증 증거: ____
  [힌트: 무엇을 바꿨고 같은 조건에서 무엇이 달라졌나]

  [힌트: 다음 사람이 취할 행동으로]
